# Bloom Highlighter usage

Bloom Highlighter helps people read and navigate source code in Visual Studio Code with clearer visual cues.

## Who it is for

- Students and beginners learning programming.
- Developers reading unfamiliar or complex code.
- People who find additional visual cues helpful for focus and navigation.

## Branding assets

Use the neutral gold-and-purple logo and matching promotional images consistently across the project description and promotional material.

- Logo: `media/branding/bloom-neutral-gold-purple.svg`
- Wide promotional banner: `media/branding/bloom-gold-purple-banner.svg`
- Square social image: `media/branding/bloom-gold-purple-social.svg`

Keep ordinary text as plain text. Do not use badges or notification lights for simple text.
